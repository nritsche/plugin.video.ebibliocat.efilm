# eBiblioCat eFilm
Kodi add-on ID: `plugin.video.ebibliocat.efilm.pitest`.

Kodi add-on for eBiblioCat eFilm.
Entertainment, movies, series, documentaries, etc from the libraries of Barcelone ebibliocat.efilm.info

Complement per Kodi - XBMC.  
Tota la programació de eBiblioCat eFilm. Llistes dels peliculas Més populares, Recien llegades, No t'ho perdis, etc.




The home menu provides All movies (A–Z), Movies by genre, Lists, and Series.
Lists and genres come from eFilm’s live directory. Lists fall back to the 25 known collections if the directory is unavailable.
The complete movie catalog is sorted locally and cached for six hours, with 24 titles per page. Genre filters apply before pagination.
Series open into seasons and episodes. Episodes use the same sign-in, loan confirmation, and playback flow as movies.
