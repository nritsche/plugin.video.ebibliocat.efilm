# eBiblioCat eFilm Kodi repository

Install `repository.ebibliocat.efilm/repository.ebibliocat.efilm-1.0.0.zip` in Kodi, then use **Install from repository → eBiblioCat eFilm repository → Video add-ons**.

Source and support: https://github.com/nritsche/plugin.video.ebibliocat.efilm
Current video add-on: 0.2.1
